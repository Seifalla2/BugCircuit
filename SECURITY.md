# Security policy

BugCircuit is an alpha developer diagnostics utility; **not a security scanner**.

Supported version for security fixes: `0.1.x` (source repository).

Please use GitHub's private vulnerability reporting feature if enabled. Otherwise, do not post exploit details or confidential data publicly; contact the maintainers via a private channel listed on their GitHub profile.

Always use only authorized test targets and review exported reports before sharing. Consult [the threat model](docs/SECURITY_MODEL.md).
