02 / THE TOOLKIT

Built for practical triage.

◈

Import evidence

Review existing HAR, workflow execution JSON, and OpenTelemetry JSON exports without saving the original uploads.

⌁

Inspect authorized URLs

Use bounded HTTP GET probes with hostname scoping. Browser capture is an optional CLI capability, not a hosted scanner.

▤

Document the findings

Generate local HTML and JSON reports with evidence identifiers, confidence labels, and recommended verification steps.

◇

Optional local intelligence

Use a locally running Ollama model to explain sanitized summaries. Deterministic diagnostics do not depend on AI.

i

Scope matters. BugCircuit is currently an alpha-stage, local-only diagnostic tool. It does not automatically repair systems, certify vulnerabilities, expose private backend logs, or guarantee a root cause.
